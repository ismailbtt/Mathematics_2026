
# Exercise 8 – Intersection Point of a Line and a Plane

## Question

Find the intersection point of:

(x, y, z) = (1, 0, 2) + t(1, 2, -1)

with the plane:

x + y + z = 4

Check the result by substituting it into both descriptions.

## Solution

### Step 1: Write the Parametric Equations

From the line equation:

x = 1 + t

y = 2t

z = 2 - t

### Step 2: Substitute into the Plane Equation

The plane equation is:

x + y + z = 4

Substitute the parametric expressions:

(1 + t) + 2t + (2 - t) = 4

Simplify:

1 + t + 2t + 2 - t = 4

2 + 2t = 4

2t = 2

t = 1

### Step 3: Calculate the Intersection Point

Substitute t = 1 into the line equations:

x = 1 + 1 = 2

y = 2(1) = 2

z = 2 - 1 = 1

Therefore, the intersection point is:

P = (2, 2, 1)

### Step 4: Verify the Point on the Line

The line is:

(x, y, z) = (1, 0, 2) + t(1, 2, -1)

For t = 1:

(1, 0, 2) + (1, 2, -1)

= (2, 2, 1)

The point belongs to the line.

### Step 5: Verify the Point on the Plane

Substitute P = (2, 2, 1):

2 + 2 + 1 = 4

5 ≠ 4

There is an arithmetic inconsistency in the claimed point, so we must recheck the calculation.

Using the original substitution:

(1 + t) + 2t + (2 - t) = 4

2 + 2t = 4

t = 1

At t = 1, the coordinates are (2, 2, 1), whose sum is 5.

The correct equation is:

1 + t + 2t + 2 - t = 4

3 + 2t = 4

2t = 1

t = 1/2

Now calculate the coordinates:

x = 1 + 1/2 = 3/2

y = 2(1/2) = 1

z = 2 - 1/2 = 3/2

Therefore, the correct intersection point is:

P = (3/2, 1, 3/2)

### Step 6: Verify the Correct Intersection Point

On the line, using t = 1/2:

(1, 0, 2) + (1/2)(1, 2, -1)

= (3/2, 1, 3/2)

On the plane:

3/2 + 1 + 3/2 = 4

4 = 4

The point satisfies both equations.

## Final Answer

The intersection point is:

P = (3/2, 1, 3/2)

The corresponding parameter is:

t = 1/2

The point belongs to both the line and the plane.
