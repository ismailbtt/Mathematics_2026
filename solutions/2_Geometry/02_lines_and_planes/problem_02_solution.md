
# Exercise 2 – A Line in Space

## Question

Given:

L: (x, y, z) = (2, -1, 3) + t(1, 2, -2)

State a point on the line and its direction vector.

Check whether P = (4, 3, -1) lies on L.

Find the point corresponding to t = -1.

## Solution

### Step 1: Identify a Point and Direction Vector

The line is given in the form:

(x, y, z) = p + tv

Comparing with the given equation:

p = (2, -1, 3)

v = (1, 2, -2)

Therefore, a point on the line is:

(2, -1, 3)

The direction vector is:

(1, 2, -2)

### Step 2: Check Whether P = (4, 3, -1) Lies on the Line

The parametric equations are:

x = 2 + t

y = -1 + 2t

z = 3 - 2t

Using the x-coordinate of P:

4 = 2 + t

t = 2

Check the y-coordinate:

y = -1 + 2(2) = 3

Check the z-coordinate:

z = 3 - 2(2) = -1

All three coordinates match.

Therefore, P lies on the line.

### Step 3: Find the Point for t = -1

Substitute t = -1:

(x, y, z) = (2, -1, 3) + (-1)(1, 2, -2)

(x, y, z) = (2, -1, 3) + (-1, -2, 2)

Therefore:

(x, y, z) = (1, -3, 5)

## Final Answer

**A point on the line:**

p = (2, -1, 3)

**Direction vector:**

v = (1, 2, -2)

**Point P = (4, 3, -1):**

P lies on the line because t = 2 satisfies all three coordinates.

**Point for t = -1:**

(1, -3, 5)
