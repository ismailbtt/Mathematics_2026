
# Exercise 9 – Distances

## Question

Compute:

1. The distance from P = (2, 3) to the line 3x + 4y - 10 = 0.
2. The distance from Q = (2, -1, 3) to the plane 2x - 2y + z - 4 = 0.

Compare the two formulas and explain their common connection with the normal direction.

## Solution

### Part 1: Distance from a Point to a Line

The given point is:

P = (2, 3)

The line is:

3x + 4y - 10 = 0

Use the point-to-line distance formula:

d = |ax₀ + by₀ + c| / √(a² + b²)

Substitute the values:

d = |3(2) + 4(3) - 10| / √(3² + 4²)

Simplify:

d = |6 + 12 - 10| / √(9 + 16)

d = 8 / √25

Therefore:

d = 8/5

### Part 2: Distance from a Point to a Plane

The given point is:

Q = (2, -1, 3)

The plane is:

2x - 2y + z - 4 = 0

Use the point-to-plane distance formula:

d = |ax₀ + by₀ + cz₀ + d| / √(a² + b² + c²)

Substitute the values:

d = |2(2) - 2(-1) + 3 - 4| / √(2² + (-2)² + 1²)

Simplify:

d = |4 + 2 + 3 - 4| / √(4 + 4 + 1)

d = 5 / √9

Therefore:

d = 5/3

### Part 3: Compare the Two Formulas

Both formulas calculate the perpendicular distance from a point to a geometric object.

For a line in two dimensions, the normal vector is:

n = (a, b)

For a plane in three dimensions, the normal vector is:

n = (a, b, c)

The denominator in each formula is the magnitude of the normal vector.

Therefore, both formulas are based on the same geometric idea: measuring distance in the normal direction.

## Final Answer

**1. Distance from P to the line:**

d = 8/5 = 1.6

**2. Distance from Q to the plane:**

d = 5/3 ≈ 1.667

Both formulas use the normal vector to calculate perpendicular distance.
