
# Exercise 3 – Plane Through a Point with a Given Normal Vector

## Question

Find the equation of the plane through P = (1, -2, 3) and perpendicular to n = (2, 1, -1).

Check the result by substituting the point P and explain the role of the normal vector.

## Solution

### Step 1: Identify the Normal Vector

We are given:

P = (1, -2, 3)

n = (2, 1, -1)

The normal vector is perpendicular to every direction lying in the plane.

### Step 2: Use the Plane Equation

The general equation of a plane is:

a(x - x₀) + b(y - y₀) + c(z - z₀) = 0

Using the point P and normal vector n:

2(x - 1) + 1(y + 2) - 1(z - 3) = 0

### Step 3: Simplify the Equation

Expand:

2x - 2 + y + 2 - z + 3 = 0

Simplify:

2x + y - z + 3 = 0

Therefore, the plane equation is:

2x + y - z + 3 = 0

### Step 4: Verify the Given Point

Substitute P = (1, -2, 3):

2(1) + (-2) - 3 + 3 = 0

2 - 2 - 3 + 3 = 0

0 = 0

The point satisfies the plane equation.

### Step 5: Explain the Role of the Normal Vector

The normal vector n = (2, 1, -1) is perpendicular to the plane.

It determines the orientation of the plane.

The point P determines the position of the plane in space.

## Final Answer

**Plane equation:**

2x + y - z + 3 = 0

**Normal vector:**

n = (2, 1, -1)

**Verification:**

Substituting P = (1, -2, 3) gives 0 = 0.

Therefore, the plane passes through the given point.
