
# Exercise 1 – Line Through Two Points

## Question

Find the equation of the line through A = (1, 2) and B = (4, -1) in parametric and general form.

Identify a direction vector and an example of a normal vector.

Check that both points satisfy the equation you obtain.

## Solution

### Step 1: Find the Direction Vector

The direction vector is:

v = B - A

v = (4 - 1, -1 - 2)

v = (3, -3)

Therefore:

v = (3, -3)

### Step 2: Find the Parametric Equation

The parametric equation of a line is:

(x, y) = A + tv

Substituting A = (1, 2) and v = (3, -3):

(x, y) = (1, 2) + t(3, -3)

Therefore:

x = 1 + 3t

y = 2 - 3t

### Step 3: Find the General Form

From the direction vector v = (3, -3), we can choose a normal vector:

n = (1, 1)

The general form is:

x + y + c = 0

Substitute point A = (1, 2):

1 + 2 + c = 0

c = -3

Therefore, the general equation is:

x + y - 3 = 0

### Step 4: Verify Both Points

For A = (1, 2):

1 + 2 - 3 = 0

For B = (4, -1):

4 - 1 - 3 = 0

Both points satisfy the equation.

## Final Answer

**Parametric form:**

x = 1 + 3t

y = 2 - 3t

**General form:**

x + y - 3 = 0

**Direction vector:**

v = (3, -3)

**Normal vector:**

n = (1, 1)

Both given points lie on the line.
